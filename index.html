Logika Matematika

Pernyataan, tabel kebenaran, ekuivalensi, dan penarikan kesimpulan.

Materi

Pernyataan & operasi logika

Pernyataan (proposisi) adalah kalimat yang bernilai benar (B) atau salah (S), tidak keduanya. Kalimat yang memuat variabel disebut kalimat terbuka dan belum punya nilai kebenaran.

Lima operasi dasar:

  • Negasi ¬p — kebalikan nilai p.
  • Konjungsi p ∧ q ("dan") — benar hanya jika keduanya benar.
  • Disjungsi p ∨ q ("atau") — salah hanya jika keduanya salah.
  • Implikasi p → q ("jika p maka q") — salah hanya jika p benar & q salah.
  • Biimplikasi p ↔ q ("p jika dan hanya jika q") — benar jika kedua nilai sama.

Konvers, invers, kontraposisi

Dari implikasi p → q:

Konvers: q → p  ·  Invers: ¬p → ¬q  ·  Kontraposisi: ¬q → ¬p

Kontraposisi ekuivalen dengan pernyataan asal. Konvers ekuivalen dengan invers.

Hukum penting

De Morgan: ¬(p ∧ q) ≡ ¬p ∨ ¬q  |  ¬(p ∨ q) ≡ ¬p ∧ ¬q
Negasi implikasi: ¬(p → q) ≡ p ∧ ¬q

Tautologi = selalu benar; Kontradiksi = selalu salah. Dua pernyataan ekuivalen (≡) bila tabel kebenarannya sama.

Penarikan kesimpulan (argumen valid)

Modus Ponens: p→q , p  ∴ q
Modus Tollens: p→q , ¬q  ∴ ¬p
Silogisme: p→q , q→r  ∴ p→r

Himpunan

Notasi, operasi himpunan, serta kardinalitas 2 dan 3 himpunan.

Materi

Konsep & notasi

Himpunan adalah kumpulan objek yang terdefinisi jelas. Penulisan: mendaftar {1, 2, 3} atau notasi pembentuk {x | sifat x}.

  • Keanggotaan: a ∈ A , b ∉ A
  • Himpunan kosong ∅ = { } , himpunan semesta S
  • A ⊆ B bila setiap anggota A juga anggota B

Operasi himpunan

Gabungan  A ∪ B = {x | x∈A atau x∈B}
Irisan     A ∩ B = {x | x∈A dan x∈B}
Komplemen  A′ = {x∈S | x∉A}
Selisih    A − B = {x | x∈A dan x∉B}

Kardinalitas & inklusi–eksklusi

n(A) = banyak anggota A. Untuk menghitung gabungan:

2 himpunan:
n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
3 himpunan:
n(A∪B∪C) = n(A)+n(B)+n(C)
  − n(A∩B) − n(A∩C) − n(B∩C)
  + n(A∩B∩C)
Sifat: komutatif, asosiatif, distributif A∩(B∪C) = (A∩B)∪(A∩C), dan De Morgan (A∪B)′ = A′∩B′.

03

Persamaan Linier

Persamaan linear satu & dua variabel, metode penyelesaian, dan penerapannya.

Materi

Persamaan linear satu variabel (PLSV)

a·x + b = c ,  a ≠ 0  ⇒  x = c − ba

Prinsip kesetaraan: melakukan operasi yang sama (tambah, kurang, kali, bagi) pada kedua ruas tidak mengubah penyelesaian.

Persamaan linear dua variabel (PLDV) & SPLDV

ax + by = c punya tak hingga penyelesaian (berupa garis). Sistem (SPLDV) = dua PLDV; penyelesaiannya titik potong kedua garis.

Metode: substitusi, eliminasi, gabungan, dan grafik.

Penerapan (aplikasi)

Langkah pemodelan: tentukan variabel → susun persamaan dari kalimat → selesaikan → tafsirkan jawaban.

Contoh. "Harga 2 buku dan 3 pena Rp 13.000; 1 buku dan 2 pena Rp 8.000." Misal buku = x, pena = y, maka 2x + 3y = 13000 dan x + 2y = 8000 → diselesaikan dengan eliminasi/substitusi.

Tema umum: harga & pembelian, umur, kecepatan-jarak-waktu, serta bilangan.

Persamaan Kuadrat

Akar, diskriminan, serta jumlah dan hasil kali akar.

Materi

Bentuk & cara penyelesaian

a·x2 + b·x + c = 0 ,  a ≠ 0

Tiga cara mencari akar:

  • Pemfaktoran
  • Melengkapkan kuadrat sempurna
  • Rumus abc:
x1,2 = −b ± √(b2 − 4ac)2a

Diskriminan

D = b2 − 4ac
Nilai DJenis akar
D > 0dua akar real berbeda
D = 0dua akar real kembar (sama)
D < 0tidak punya akar real

Jumlah & hasil kali akar

x1 + x2 = −ba   ·   x1 · x2 = ca

Menyusun persamaan baru dari akar:

x2 − (x1 + x2)·x + (x1·x2) = 0

05

Pertidaksamaan Kuadrat

Garis bilangan, uji tanda, dan himpunan penyelesaian.

Materi

Bentuk & langkah

a·x2 + b·x + c   { < , ≤ , > , ≥ }   0
  1. Nolkan satu ruas.
  2. Cari pembuat nol (akar) dari ax²+bx+c = 0.
  3. Gambar garis bilangan & uji tanda tiap interval (atau pakai arah buka parabola).
  4. Tulis himpunan penyelesaian sesuai tanda yang diminta.

Pola untuk a > 0, akar x1 < x2

ax²+bx+c < 0  ⇒  x1 < x < x2  (di dalam)
ax²+bx+c > 0  ⇒  x < x1 atau x > x2  (di luar)
Tanda ≤ / ≥ menyertakan titik ujung (pakai tanda sama dengan). Jika a < 0, arah pertidaksamaan dibalik.

Fungsi Kuadrat

Grafik parabola, titik puncak, sumbu simetri, dan nilai ekstrem.

Materi

Bentuk & grafik

f(x) = a·x2 + b·x + c
  • a > 0 → parabola terbuka ke atas (punya nilai minimum).
  • a < 0 → terbuka ke bawah (punya nilai maksimum).

Unsur penting

Sumbu simetri:  x = −b2a
Titik puncak:  ( −b2a , −D4a ) ,  D = b²−4ac
Potong sumbu-Y: (0, c)  ·  Potong sumbu-X: akar ax²+bx+c=0

Menyusun fungsi dari titik puncak (xp, yp):  f(x) = a(x − xₚ)² + yₚ.

Titik, Garis, Bidang & Ruang

Unsur geometri, kedudukan, dan geometri koordinat bidang.

Materi

Unsur dasar (tak terdefinisi)

UnsurDimensiKeterangan
Titik0dilambangkan huruf kapital A, B, …
Garis1himpunan titik, memanjang tak terbatas
Bidang2permukaan datar tak terbatas
Ruang3himpunan semua titik

Kedudukan

  • Dua garis: berpotongan · sejajar (sebidang, tak berpotongan) · berimpit · bersilangan (tidak sebidang — hanya di ruang).
  • Garis & bidang: terletak pada bidang · sejajar · menembus (memotong).
  • Dua bidang: berimpit · sejajar · berpotongan (membentuk sebuah garis).

Geometri koordinat (bidang)

Untuk titik A(x₁, y₁) dan B(x₂, y₂):

Jarak:  d = √( (x₂−x₁)² + (y₂−y₁)² )
Titik tengah:  M = ( x₁+x₂2 , y₁+y₂2 )
Gradien:  m = y₂ − y₁x₂ − x₁
Pengayaan — jarak titik (x₀,y₀) ke garis ax+by+c=0:  |ax₀+by₀+c| / √(a²+b²).
